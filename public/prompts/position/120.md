## K-STAR-K 프레임워크 핵심 가이드

**자기소개서 작성 시 활용할 K-STAR-K 프레임워크:**

- **K(Key Point)**: 핵심 역량과 경험 요약 - "FSDP/Deepspeed를 활용한 대규모 모델 학습 최적화 경험"
- **S(Situation)**: 상황 설명 - "T5-XXL 모델 학습 시 GPU 메모리 부족 문제 직면"
- **T(Task)**: 과제 설명 - "8대 A100으로 175B 파라미터 모델 학습 환경 구축 필요"
- **A(Action)**: 행동 설명 - "FSDP Stage 3 적용, gradient checkpointing 구현, mixed precision 최적화"
- **R(Result)**: 결과 설명 - "메모리 사용량 75% 감소, 학습 속도 2.3배 향상, 비용 60% 절감"
- **K(Knockout)**: 기여 가능성 - "HyperCLOVA X의 효율적 학습 시스템 구축과 소버린 AI 생태계 확장에 기여"

더 자세한 설명이 필요하시면 "K-STAR-K 상세설명 요청"이라고 말씀해주세요.

## 산업 도메인 분석

### 산업 개요

- **산업 정의**: 대규모 언어 모델(LLM) 및 생성형 AI 기술 개발/서비스
- **시장 현황**: 2024-2030 글로벌 LLM 시장 CAGR 35.9%, 2030년 354억 달러 예상
- **비즈니스 모델**: API 기반 서비스, 기업 맞춤형 솔루션, 오픈소스 생태계

### 산업 트렌드 (2024-2025)

- **기술 혁신**:
  - Agentic AI 및 LAM(Large Action Model) 부상
  - 멀티모달 모델 확산 (Vision-Language Models)
  - 효율적 학습 기법 발전 (FSDP, Pipeline Parallelism)
  - RAG 및 Function Calling 고도화
- **시장 변화**:
  - 오픈소스 모델 선호도 증가 (46% 기업 관심)
  - 멀티 LLM 전략 보편화 (3개 이상 모델 활용)
  - 소버린 AI 중요성 부각
- **경쟁 환경**: OpenAI, Google, Meta vs 지역 특화 모델 경쟁

### 미래 전망

- **성장 동력**: 산업별 특화 모델, 엣지 AI, 실시간 추론
- **도전 과제**: 데이터 품질, 컴퓨팅 비용, AI 안전성
- **기술 방향성**: 효율적 학습, 멀티모달 통합, 자율 에이전트

## 채용공고 핵심 분석

### 1) HyperCLOVA X Agentic 역량 개발 (모델러)

**필수 역량:**

- LLM 활용 에이전트(챗봇, RAG 시스템) 모델 학습
- 프롬프트 엔지니어링, 파인튜닝, 데이터 전처리
- Python, Hugging Face, PyTorch/TensorFlow

**우대사항:**

- 웹 크롤링, 도커, CI/CD
- 모델 경량화(양자화, 프루닝), 추론 최적화

### 2) HyperCLOVA X Agentic 역량 개발 (리서치 엔지니어)

**필수 역량:**

- TypeScript/JavaScript, Python 3년 이상
- Next.js 프론트엔드 및 Python API 서버
- Kubernetes, 도커, CI/CD, 애자일

**우대사항:**

- LLM 프롬프트 엔지니어링
- AI/LLM Framework(LangChain, LangGraph)

### 3) HyperCLOVA X 이미지/비디오 생성 역량 개발

**필수 역량:**

- 분산 학습(FSDP, Deepspeed) 또는 데이터 분산 처리
- Python + PyTorch 실무 능숙
- 기술 협업 능력

**우대사항:**

- 대규모 GPU 클러스터(SuperPOD) 활용
- Diffusion 모델 구현/튜닝
- Cuda/Triton Kernel 개발

### 4) HyperCLOVA X 학습 시스템 개발/최적화

**필수 역량:**

- 대규모 분산 학습 시스템 최적화 3년 이상
- FSDP, Deepspeed, Megatron-lm 경험
- LLM 학습/inference 분석 능력

**우대사항:**

- GPU architecture 및 cuda kernel 개발
